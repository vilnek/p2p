# Third-party notices

P2P Talk is licensed under the [Apache License 2.0](LICENSE). The built app (`dist/p2p.html`) includes
the open-source libraries below, each under its own licence. This list covers the production
dependencies only (`npm ls --omit=dev`); build and test tools (Vite, TypeScript, Vitest, Playwright,
ws) are not shipped in the app.

| Library | Version | Licence | Used for | Source |
|---|---|---|---|---|
| @noble/curves | 1.9.7 | MIT | Ed25519, X25519, secp256k1 Schnorr (relay events) | <https://github.com/paulmillr/noble-curves> |
| @noble/hashes | 1.8.0 | MIT | SHA-256, SHA-512, HKDF, PBKDF2; Argon2id fallback for the chat lock | <https://github.com/paulmillr/noble-hashes> |
| hash-wasm | 4.12.0 | MIT | Argon2id (WebAssembly) for the chat lock's secret code | <https://github.com/Daninet/hash-wasm> |
| @scure/base | 1.2.6 | MIT | text encodings (used by @scure/bip39) | <https://github.com/paulmillr/scure-base> |
| @scure/bip39 | 1.6.0 | MIT | the 24-word phrase | <https://github.com/paulmillr/scure-bip39> |
| jsqr | 1.4.0 | Apache-2.0 | reading QR codes when the browser has no built-in reader | <https://github.com/cozmo/jsQR> |
| lucide | 1.50.0 | ISC | a few line icons | <https://github.com/lucide-icons/lucide> |
| uqr | 0.1.3 | MIT | drawing QR codes | <https://github.com/unjs/uqr> |

To check this list: `npm ls --omit=dev --all`.
